# Say the word

אפליקציית תרגול מילים באנגלית. הזיהוי רץ במכשיר, בלי שרת ובלי אינטרנט.

## הקבצים

| קובץ | מה זה | משתנה? |
|---|---|---|
| `index.html` | הדף עצמו | כן, כאן עורכים |
| `vosk.js` | מנוע הזיהוי (WebAssembly) | כמעט לעולם לא |
| `model.tar.gz` | מודל אנגלית, 29MB | לא |
| `sw.js` | עבודה ללא אינטרנט | נדיר |
| `.nojekyll` | מכבה את Jekyll ב-GitHub Pages | לא |

## העלאה לאוויר — GitHub Pages

הקבצים כבר בריפו. מה שנשאר זה להדליק את Pages פעם אחת:

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, תיקייה **/ (root)** → Save.

אחרי דקה־שתיים האתר עולה בכתובת `https://USER.github.io/REPO/`.
מכאן כל דחיפה ל-`main` עולה לאוויר לבד.

את `index.html` אפשר לערוך ישירות באתר GitHub — הוא קטן ולא נוגע
במגבלת ה-25MB של העלאה דרך הדפדפן. את `model.tar.gz` (28MB) לא ניתן
להעלות ככה, ולכן החלפה שלו נעשית משורת הפקודה:

```bash
git add model.tar.gz
git commit -m "new model"
git push
```

קובץ `.nojekyll` שיושב בריפו מבקש מ-Pages להגיש את הקבצים כמו שהם,
בלי מנוע Jekyll שמסתיר קבצים שמתחילים בקו תחתון.

## המילים

16 מילים מוכנות. כפתור **אוצר המילים** פותח חלונית ניהול: מוסיפים תמונה
מהקטלוג, מוחקים, משנים סדר, ומאפסים לברירת המחדל. השם באנגלית קבוע לפי
האימוג'י — אין הקלדה. נשמר בדפדפן של המכשיר.

לשינוי הרשימה הקבועה לכולם — עורכים את `DEFAULT_WORDS` ב-`index.html`.
המילון של המודל מכיל כ-152,000 מילים באנגלית.

## בכיתה

פתיחה ראשונה עם אינטרנט מורידה את המודל, פעם אחת, עם פס התקדמות.
בזמן ההורדה 🔊 ו-⏭️ כבר עובדים — רק המיקרופון מחכה.
אחר כך "הוסף למסך הבית", ועובד גם בלי רשת. ההקלטות לא יוצאות מהמכשיר.

הקריינית מדברת עברית: "כל הכבוד!" בהצלחה, "נסו שוב" בכישלון. המילה
שמתרגלים נאמרת באנגלית, כמובן. אם במכשיר אין קול עברי מותקן (יש ב-iPhone
ובאנדרואיד; בכרום על דסקטופ לפעמים אין) המשוב הקולי פשוט שותק, במקום
שהדפדפן יקריא עברית בקול אנגלי. הצבע, ה-🎉 והכוכבים עובדים בכל מקרה.

רעש רקע, נשימה או "אממ" לא נחשבים ניסיון: המיקרופון ממשיך להקשיב עד
שנשמעת מילה מהרשימה או עד שעוברות 4 שניות. בין ניסיונות המנוע לא מעבד
אודיו בכלל, כדי לחסוך סוללה.

הדף גם מבקש מהדפדפן לשמור על המטמון כשנגמר מקום (`storage.persist`);
ב-Chrome זה מאושר אוטומטית אחרי "הוסף למסך הבית".
בלי רשת הדף והמודל עולים מהמטמון מיד. אם ה-WiFi מחובר אבל אין אינטרנט,
הדף מחכה לרשת עד 3 שניות ואז עולה מהמטמון.

את פס ההתקדמות אי אפשר לקבל מהמנוע — הוא לא מדווח כמה ירד — ולכן הדף
מוריד את `model.tar.gz` בעצמו ומניח אותו במטמון, והמנוע לוקח אותו משם.
מכאן ששם המטמון ב-`index.html` וב-`sw.js` חייב להישאר זהה.
