# Say the word

אפליקציית תרגול מילים באנגלית. הזיהוי רץ במכשיר, בלי שרת ובלי אינטרנט.

האפליקציה נבנתה ב-Google AI Studio, אבל היא לא קוראת ל-Gemini ולא לשום
שירות חיצוני. אין מפתח API, אין קריאת רשת אחת בזמן ריצה, ו-`.env.example`
ריק בכוונה. כל מה שצריך כדי להריץ אותה יושב בריפו הזה.

## העלאה לאוויר

יש שני מסלולים, והם לא שקולים. בגלל שהאפליקציה יושבת בשורש באחד ותחת
`/REPO/` בשני, כל נתיב בדף, ב-`sw.js` ובמניפסט יחסי (`./`).

### GitHub Pages — המסלול שבשבילו האפליקציה נבנתה

הקבצים כבר בריפו. מה שנשאר זה להדליק את Pages פעם אחת:

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, תיקייה **/ (root)** → Save.

אחרי דקה־שתיים האתר עולה בכתובת `https://USER.github.io/REPO/`.
מכאן כל דחיפה ל-`main` עולה לאוויר לבד.

את `index.html` אפשר לערוך ישירות באתר GitHub. את `model.tar.gz` (29MB)
לא — הוא מעל מגבלת ה-25MB של העלאה דרך הדפדפן, ולכן החלפה שלו נעשית
משורת הפקודה (`git add model.tar.gz && git commit && git push`).

### AI Studio — נוח לשיתוף, אבל לא לכיתה

`server.js` ו-`package.json` קיימים רק בשביל המסלול הזה: AI Studio מפרסם
את האפליקציה כשרת Node על Cloud Run, ולא כאתר סטטי.

זה טוב לשלוח קישור ולהראות למישהו. **לפני שמסתמכים על זה בכיתה יש לבדוק
שני דברים**, ששניהם נוגעים בדיוק בלב האפליקציה — העבודה ללא אינטרנט:

- החלון בתוך AI Studio הוא iframe מאתר אחר. דפדפנים מפרידים אחסון לפי
  אתר, וחלקם חוסמים Service Worker ב-iframe כזה לגמרי. מה שצריך לבדוק זה
  הקישור הישיר לאפליקציה שפורסמה, לא התצוגה בתוך AI Studio.
- יש דיווחים שצנרת הפרסום של AI Studio מחליפה את ה-Service Worker של
  האפליקציה באחד משלה. לא אימתנו את זה מול תיעוד רשמי, אבל אם האפליקציה
  לא עולה במצב טיסה אחרי שכבר הורידה את המודל — זו הסיבה הראשונה לבדוק.

ב-GitHub Pages שתי השאלות האלה לא קיימות: הקבצים מוגשים כמו שהם, מאתר
משל עצמם, וה-Service Worker הוא זה שבריפו.

## המילים

16 מילים מוכנות. המילה הבאה נבחרת בהגרלה, גם הראשונה כשפותחים, רק לא
אותה מילה פעמיים ברצף.

כפתור **אוצר המילים** פותח חלונית ניהול: מוסיפים תמונה מהקטלוג, מוחקים,
ומאפסים לברירת המחדל. לחיצה על מילה קופצת אליה. השם באנגלית קבוע לפי
האימוג'י — אין הקלדה. נשמר בדפדפן של המכשיר.

מתחת למילה באנגלית מופיע איך אומרים אותה באותיות עבריות (cat — קֶט), בשביל
ילד שעוד לא קורא אנגלית. מתג בהגדרות מכבה את זה, והבחירה נשמרת במכשיר.

לשינוי הרשימה הקבועה לכולם — עורכים את `DEFAULT_WORDS` ב-`words.js`.
המילון של המודל מכיל כ-152,000 מילים באנגלית.

## בכיתה

פתיחה ראשונה עם אינטרנט מורידה את המודל, פעם אחת, עם פס התקדמות.
בזמן ההורדה 🔊 ו-⏭️ כבר עובדים — רק המיקרופון מחכה. אחר כך "הוסף למסך
הבית", ועובד גם בלי רשת; אחרי ההתקנה כרום גם לא מוחק את המודל כשנגמר מקום.
אם ה-WiFi מחובר אבל אין אינטרנט, הפתיחה מתעכבת כמה שניות ואז עולה מהמטמון.
ההקלטות לא יוצאות מהמכשיר.

הקריינית מדברת עברית: "כל הכבוד!" בהצלחה, "נסו שוב" בכישלון. המילה
שמתרגלים נאמרת באנגלית. אם במכשיר אין קול עברי מותקן (יש ב-iPhone
ובאנדרואיד; בכרום על דסקטופ לפעמים אין) המשוב הקולי שותק, והצבע, ה-🎉
והכוכבים עובדים בכל מקרה. מצב השמע נשמר במכשיר.

כל מילה נכונה מוסיפה כוכב, שלושה כוכבים מתחלפים במדליה 🏅, וחמש מדליות
בגביע 🏆. הספירה מתאפסת בכל פתיחה של הדף.

רעש רקע, נשימה או "אממ" לא נחשבים ניסיון: המיקרופון ממשיך להקשיב עד
שנשמעת מילה מהרשימה או עד שנגמר חלון ההקשבה — כמה שניות, קצר יותר ברמת
התאמה גבוהה. חיווי ההקלטה של הדפדפן נשאר דולק בין ניסיונות, ונכבה כשהדף
יורד מהמסך.

## הרצה ובדיקות

```bash
python3 -m http.server 8000                        # בלי להתקין כלום
npm install && npm run dev                         # השרת של AI Studio, פורט 3000
```

ואז http://localhost:8000 (או 3000) — לא בלחיצה כפולה על הקובץ,
המיקרופון חסום ב-file://

```bash
npm install && npx playwright install chromium     # פעם אחת
npm test
```

`test.js` פותח את הדף בכרום ומרים גם את `server.js`. הבדיקות הן לא כיסוי
מלא אלא המקומות שכבר נשברו פעם, וכל קבוצה מסבירה בהערה מה היא שומרת.

`package-lock.json` נועל את הגרסאות. בלעדיו כל `npm install` מושך את
playwright האחרונה, שדורשת כרומיום אחר, והבדיקות נשברות בלי שאף אחד נגע
בקוד. playwright נעולה על 1.56.1 כי זה הכרומיום שמותקן מראש בסשנים של
Claude Code בענן; גרסה אחרת מפילה שם את `npm test` כבר בפתיחת הדפדפן.
לעדכון מכוון: `npm update`, ולראות ש-`npm test` עדיין ירוק — גם בענן.
