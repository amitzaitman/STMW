# Say the word

אפליקציית תרגול מילים באנגלית. הזיהוי רץ במכשיר, בלי שרת ובלי אינטרנט.

האפליקציה נבנתה ב-Google AI Studio, אבל היא לא קוראת ל-Gemini ולא לשום
שירות חיצוני. אין מפתח API ואין קריאת רשת אחת בזמן ריצה. כל מה שצריך
כדי להריץ אותה יושב בריפו הזה.

## העלאה לאוויר

יש שני מסלולים, והם לא שקולים. בגלל שהאפליקציה יושבת בשורש באחד ותחת
`/REPO/` בשני, כל נתיב בדף, ב-`sw.js` ובמניפסט יחסי (`./`).

### GitHub Pages — המסלול שבשבילו האפליקציה נבנתה

הקבצים כבר בריפו. מה שנשאר זה להדליק את Pages פעם אחת:

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, תיקייה **/ (root)** → Save.

אחרי דקה־שתיים האתר עולה בכתובת `https://USER.github.io/REPO/`.
מכאן כל דחיפה ל-`main` עולה לאוויר לבד. מכשיר שכבר פתח את האפליקציה יכול
לקבל עוד כמה דקות את הגרסה הקודמת; לחיצה ארוכה על 🔄, בפינה של מסך הפתיחה
מול 🔒, טוענת את האחרונה.

את `index.html` אפשר לערוך ישירות באתר GitHub. את `model.tar.gz` (29MB)
לא — הוא מעל מגבלת ה-25MB של העלאה דרך הדפדפן, ולכן החלפה שלו נעשית
משורת הפקודה (`git add model.tar.gz && git commit && git push`).

מודל שהוחלף באותו שם מגיע רק למכשירים שעוד לא טענו את המודל: Vosk מחלץ
אותו פעם אחת ל-IndexedDB של המכשיר, לפי הכתובת שלו, ולא מבקש אותו שוב —
גם לא כשהמטמון מתחלף. כדי שיגיע גם למכשירים קיימים צריך שם קובץ חדש (לא
`?v=`, שה-service worker מתעלם ממנו בקבצים הכבדים), וכל קובץ בריפו שמפנה
ל-`model.tar.gz` עובר אליו. העותק המחולץ הישן נשאר במכשירים, ב-IndexedDB.
הארכיון עצמו לא נשאר: אחרי שהמודל נטען הוא נמחק מ-Cache Storage.

### AI Studio — נוח לשיתוף, אבל לא לכיתה

`server.js` קיים רק בשביל המסלול הזה: AI Studio מפרסם את האפליקציה כשרת
Node על Cloud Run, ולא כאתר סטטי.

זה טוב לשלוח קישור ולהראות למישהו. **לפני שמסתמכים על זה בכיתה יש לבדוק
שני דברים**, ששניהם נוגעים בדיוק בלב האפליקציה — העבודה ללא אינטרנט:

- החלון בתוך AI Studio הוא iframe מאתר אחר. דפדפנים מפרידים אחסון לפי
  אתר, וחלקם חוסמים Service Worker ב-iframe כזה לגמרי. מה שצריך לבדוק זה
  הקישור הישיר לאפליקציה שפורסמה, לא התצוגה בתוך AI Studio.
- יש דיווחים שצנרת הפרסום של AI Studio מחליפה את ה-Service Worker של
  האפליקציה באחד משלה. לא אימתנו את זה מול תיעוד רשמי, אבל אם האפליקציה
  לא עולה במצב טיסה אחרי שכבר הורידה את המודל — זו הסיבה הראשונה לבדוק.

ב-GitHub Pages שתי השאלות האלה לא קיימות: הקבצים מוגשים כמו שהם, מאתר
משל עצמם, וה-Service Worker הוא זה שבריפו.

## מה הילד רואה

האפליקציה נפתחת במסך עם ▶ אחד, ציפור סגולה ושם הילד, אם יש. ▶ מפעיל את הקול
ומבקש אישור למיקרופון, ורק אחריו מופיעה המילה הראשונה. מכאן בכל רגע יש על
המסך דבר אחד סגול ללחוץ עליו, ומה שאי אפשר להשתמש בו עכשיו לא מופיע. הציפור
אומרת בבועה מה לעשות, בסמל ועד שלוש מילים מנוקדות ("אִמְרוּ בְּאַנְגְּלִית",
"זוֹכְרִים?"), ויד שקופה מדגימה את הפעולה בפעם הראשונה ואחרי המתנה, בלי
ללחוץ באמת. השמע דלוק כברירת מחדל: המילה באנגלית היא הדוגמה. בכיתה כדאי
אוזניות.

ליד 🎤 יש שני כפתורים קטנים: 🔊 לשמוע שוב (בכרטיס בלי כתב הוא גם מראה אותו,
ונחשב עזרה), ו-⏭️ לוויתור. הם לא מופיעים כשהמכשיר מדבר, מקשיב או חוגג.
"חזור" של המערכת, או לחיצה ארוכה על 🏠 בפינה, מחזירים למסך הפתיחה.

**הכנת המכשיר:** מכשיר חדש, שלא נשמר בו כלום, נפתח במסך אחד למבוגר ולא
במסך הפתיחה. מנוע הדיבור יורד שם עם פס התקדמות, ו-✓ אומר שמעכשיו המשחק עובד
גם בלי אינטרנט. כפתור מאשר את המיקרופון וסוגר אותו עד ▶, כפתור משמיע מילה
באנגלית, אפשר לכתוב את שם הילד, וכתוב איך נכנסים להגדרות. "סיימנו" עובר למסך
הפתיחה, וההכנה לא חוזרת; הכנה שנסגרה באמצע חוזרת בפתיחה הבאה, ו"בדיקת המכשיר"
באזור המבוגר פותח אותה שוב. מכשיר שהאפליקציה כבר נפתחה בו, לפני שהייתה הכנה,
לא רואה אותה.

**למבוגרים:** לחיצה ארוכה, שתי שניות, על 🔒 בפינה של מסך הפתיחה (וגם בסוף
סבב ובמסך "קראו למבוגר"), ואז מקלידים מספר שכתוב באנגלית. שם ההגדרות: מי
משחק, רשימת המילים והערכות, רמת ההתאמה, אומרים או כותבים, התעתיק, השמע,
מה נאמר בסבב האחרון לבד ומה בעזרה, והסל עם המילים באנגלית. כשמשהו לא בסדר במכשיר — מיקרופון חסום,
מנוע שלא נטען, אין קול באנגלית — זה כתוב שם, עם "נסו שוב", והילד רואה "קראו
למבוגר" עם ▶ שממשיך לשחק בלי לדבר.

## המילים

רשימת מילים מוכנה מראש, והמילים באות ממנה בסבבים קצרים. סבב מתחיל במילה
שהילד כבר אומר, חוזר על מילים שהגיע יומן לחזור ועל מילים שעוד לא הצליח בהן
לבד, ומוסיף כמה מילים חדשות — הקלות קודם, מנושאים שונים, ולא שתי מילים
שקל לבלבל ביניהן, כמו ship ו-sheep. מילה חדשה חוזרת עוד פעם בהמשך הסבב.
כמה מילים חדשות נכנסות לכל סבב נקבע לפי ההצלחה של הילד בניסיון הראשון.
מילה שהילד כבר אמר לבד מוצגת בלי המילה באנגלית ובלי התעתיק, רק התמונה, כדי
שישלוף אותה מהזיכרון.

כשהשמע דלוק, מילה שהילד עוד לא אמר לבד מתחילה בשמיעה, עד שיבחר את התמונה
שלה בניסיון הראשון: הדף אומר אותה, והילד בוחר את התמונה שלה מבין שלוש,
בעיגולים מפוזרים. התמונות "ישנות" עד שהמילה נגמרת. תמונה שגויה דוהה והמילה
נשמעת שוב, בלי רעידה ובלי צליל; הנכונה מוריקה, המילה נאמרת שוב עם הכתב, ו-🎤
מופיע כשהיא נגמרת: "אני אומר, אתם אומרים". בלי שמע, או במכשיר בלי קול
באנגלית, המילה מוצגת עם הכתב, ותגיע לשלב הזה כשיהיה שמע. כל עוד מנוע הזיהוי
יורד, או כשהמיקרופון חסום, כל מילה היא שומעים ובוחרים, בלי אמירה.

ילד שכבר אמר שלוש מילים עובר במסלול מהיר: מילה חדשה מוצגת לו רק בתמונה, עם
❓, ומי שאומר אותה נכון מדלג על ההסבר. בדיקה שלא מצליחה — אמירה שלא התקבלה,
🔊 ("לא יודעים?") או ⏭️ — מסיימת את המסלול, בלי רעידה ובלי צליל: הכרטיס נצבע
בגוון של "מלמדים", והמילה מופיעה כתובה ונשמעת. מילים שאומרים כמעט כך גם
בעברית (pizza, banana, taxi…) נבדקות כך לכל ילד; הרשימה ב-`words.js`. שלוש
המילים הראשונות של ילד חדש, גם מילים כאלה, תמיד נלמדות קודם.

שורת נקודות דקה מעל הכרטיס מראה כמה מילים נשארו בסבב. בסוף הסבב התמונות של
מה שתורגל בו נכנסות כמדבקות שוות, ומילה שנכנסה עכשיו לסל קופצת אליו; שום מילה
לא נאמרת שם, ו-▶ מופיע כשזה נגמר. בסל כל מילה שהילד אמר לבד מהתמונה בשני ימים
שונים, ומה שנכנס אליו נשאר בו. הילד רואה אותו במסך הפתיחה, תמונות בלבד; באזור
המבוגר הוא עם המילים באנגלית. מילה שנפלה לכיס קופצת ממנו כשהיא חוזרת בהמשך
הסבב. טעינה מחדש של הדף מתחילה סבב חדש.

באזור המבוגר, **רשימת המילים שבתרגול** מציגה את הרשימה: מוחקים, ומוסיפים
תמונה מהמאגר. **איפוס מילים והגדרות** מחזיר לברירת המחדל. השם באנגלית קבוע לפי
האימוג'י — אין הקלדה. נשמר בדפדפן של המכשיר.

במאגר מסננים לפי נושא (פירות, חיות הבית, תחבורה…) ולפי רמת קושי, ומה
שמוצג נכנס לתרגול בלחיצה אחת: **▶ תרגלו רק את האלה** מחליף את הרשימה, אחרי
אישור, ו**הוסיפו** מצרף לרשימה הקיימת את מה שעוד לא בה. הכרטיס **ערכות
לפי נושא ורמה** בהגדרות מגיע לשם ישר. הרמה נקבעה לכל מילה בנפרד, לילד
שעברית היא שפת האם שלו; השיקול כתוב בראש `words.js`.

מתחת למילה באנגלית מופיע איך אומרים אותה באותיות עבריות (cat — קֶט), בשביל
ילד שעוד לא קורא אנגלית. מתג באזור המבוגר מכבה את זה, והבחירה נשמרת במכשיר.

לשינוי הרשימה הקבועה לכולם — עורכים את `DEFAULT_WORDS` ב-`words.js`.
מילה חדשה נכנסת שם לאחד הנושאים ב-`THEMES`, עם רמה, ו-`npm test` נופל
אם המודל לא מכיר אותה.
המילון של המודל מכיל כ-152,000 מילים באנגלית.

## אומרים וכותבים

שני תרגולים על אותה רשימת מילים. ב-🎤 אומרים את המילה למיקרופון, והטבעות
סביבו זזות עם הקול. ב-🔤 המילה באנגלית מוסתרת, נאמרת כשהיא מופיעה, והילד בונה
אותה מהאותיות שלה, מעורבבות, משמאל לימין: המשבצת הבאה זוהרת, וחץ מראה את
הכיוון. כל אות נכנסת, גם לא נכונה, ולחיצה עליה מחזירה אותה לבנק. המילה נבדקת
רק כשהיא מלאה: הנכונות נשארות בירוק, והשגויות חוזרות לבנק והמילה נשמעת שוב,
בלי עונש. 💡 ממלא את המשבצת הראשונה שאין בה האות הנכונה. התעתיק נשאר.

**סוג התרגול** נבחר באזור המבוגר, וגם במסך הפתיחה, מתחת ל-▶, בלחיצה ארוכה
על אחד משלושת הסמלים. **מעורב**, ברירת המחדל, משלב סבב כתיבה כל סבב
שלישי, רק אחרי שהילד כבר אומר שלוש מילים, ורק במילים שהוא אומר. **אומרים** או
**כותבים** נועלים תרגול אחד; בכתיבה שמבוגר בחר הסבב מתמלא גם במילים אחרות.
הבחירה נשמרת במכשיר. כשאין מנוע זיהוי וגם אין קול באנגלית, הסבב הוא כתיבה
בלי קשר לבחירה, עד שאחד מהם חוזר. לכל אחד מהשניים סבב משלו, ומעבר ביניהם
מתחיל סבב חדש.

## כמה ילדים במכשיר אחד

באזור המבוגר, תחת **של מי ההגדרות?**, ➕ מוסיף שם. לכל שם רשימת מילים, רמת
התאמה, תעתיק ובחירה בין אומרים לכותבים משלו. השמע משותף לכל המכשיר, כי הוא
תלוי בחדר ולא בילד. שם חדש מתחיל מהעתק של מה שמופיע באותו רגע, כך שרשימה
שהוכנה לכיתה עוברת לכל ילד שנוסף אחריה. לחיצה על שם מחליפה את ההגדרות מיד,
והסגירה חוזרת למסך הפתיחה, עם השם שלו. האפליקציה נפתחת על הילד האחרון
שנבחר.

מה שנשמר במכשיר לפני שהוסיפו שמות נשאר כמו שהוא, תחת **בלי שם**. מי שלא
מוסיף שמות רואה שם רק את ➕. האיפוס מאפס רק את הילד שנבחר, ו-🗑️
מוחק את השם ואת כל מה שנשמר לו, אחרי אישור.

המכשיר שומר לכל ילד גם את הניסיונות שלו: באיזו מילה, אם התקבלה ובאיזה
ניסיון, ומה המנוע שמע. הקלטות לא נשמרות. מהם נבנים הסבבים והסל. שם חדש
מתחיל בלי ניסיונות, האיפוס לא נוגע בהם, ו-🗑️ מוחק אותם עם השם.

## בכיתה

פתיחה ראשונה עם אינטרנט מורידה את המודל, פעם אחת, בזמן הכנת המכשיר. מי
שמדלג על ההמתנה רואה את פס ההתקדמות באזור המבוגר; הילד בינתיים משחק בשומעים
ובוחרים, ו"דינג" רך אומר שמכאן יש גם אמירה. אחר כך "הוסף למסך
הבית", ועובד גם בלי רשת; אחרי ההתקנה כרום גם לא מוחק את המודל כשנגמר מקום.
אם ה-WiFi מחובר אבל אין אינטרנט, הפתיחה מתעכבת כמה שניות ואז עולה מהמטמון.
ההקלטות לא יוצאות מהמכשיר.

המילה שמתרגלים נאמרת באנגלית, רק אחרי שהילד שמע אותה כבר בתור הזה או ביקש:
בכרטיס שהגיע אליו בלי לשמוע, המכשיר לא אומר אותה מעצמו, כדי שהצלחה לבד
תיחשב לבד. בהצלחה הכרטיס מוריק, יש קונפטי וצליל קצר עולה. אין צליל טעות ואין
הקראה בעברית. השמע נדלק ונכבה באזור המבוגר, והבחירה נשמרת במכשיר.

באמירה, מילה שלא התקבלה רועדת, ואחר כך, כשהשמע דלוק, המילה נשמעת באנגלית
ו-🎤 חוזר כשהיא נגמרת. מילה שהוצגה בלי כתב מקבלת אותו בחזרה, כך שגם בלי שמע
יש דוגמה. אחרי פעם שנייה שלא התקבלה הכרטיס נופל לכיס, "נַחֲזֹר לָזֶה", והמילה
חוזרת עוד פעם באותו סבב, כמה מילים אחר כך — אם נשארו בו מספיק מילים. אחרת
היא חוזרת בסבב אחר.

כל הצלחה נראית לילד אותו דבר. מה שנאמר או נכתב בניסיון הראשון, בלי עזרה,
רואה המבוגר באזור שלו, בסבב האחרון. בכתיבה 🔊 הוא ההכתבה עצמה, ולא עזרה.
אין מספרים ואין ניקוד.

🎤 טורקיז כל עוד המיקרופון מקשיב. ההקשבה מתחילה כבר כשנוגעים בכפתור, כך
שאפשר להחזיק עליו את האצבע בזמן הדיבור; רק כשהמיקרופון צריך להיפתח —
בפעם הראשונה, אחרי שהאפליקציה ירדה מהמסך, או אחרי שהמיקרופון נותק — היא מתחילה כשמרימים את
האצבע.

רעש רקע, נשימה או "אממ" לא נחשבים ניסיון: המיקרופון ממשיך להקשיב עד
שנשמעת מילה מהרשימה או עד שנגמר חלון ההקשבה — כמה שניות, קצר יותר ברמת
התאמה גבוהה. גם חלון שנגמר בלי מילה, או אפליקציה שירדה מהמסך באמצע, אינם
ניסיון: "לֹא שָׁמַעְתִּי", ו-🎤 קופץ פעם אחת. בשתיקה השנייה באותה מילה היד מצביעה
על 🔊, ובשלישית המילה עוברת להמשך הסבב, בלי שזה נרשם כוויתור. חיווי ההקלטה
של הדפדפן נשאר דולק בין ניסיונות, ונכבה כשהדף יורד מהמסך.

## הרצה ובדיקות

```bash
python3 -m http.server 8000                        # בלי להתקין כלום
npm install && npm run dev                         # השרת של AI Studio, פורט 3000
```

ואז http://localhost:8000 (או 3000) — לא בלחיצה כפולה על הקובץ,
המיקרופון חסום ב-file://

```bash
npm install && npx playwright install chromium     # פעם אחת
npm test
```

`test.js` פותח את הדף בכרום ומרים גם את `server.js`.

`package-lock.json` נועל את הגרסאות. בלעדיו כל `npm install` מושך את
playwright האחרונה, שדורשת כרומיום אחר, והבדיקות נשברות בלי שאף אחד נגע
בקוד. הגרסה הנעולה של playwright היא זו של הכרומיום שמותקן מראש בסשנים
של Claude Code בענן; גרסה אחרת מפילה שם את `npm test` כבר בפתיחת הדפדפן.
לעדכון מכוון: `npm update`, ולראות ש-`npm test` עדיין ירוק — גם בענן.
